# MediaFit — Final Edition

Локальный сайт для сжатия и подготовки изображений и коротких видео. Продолжение endterm-проекта Multimedia File Formats, группа IT-2602.

## Запуск

Откройте **index.html** в актуальном Chrome или Microsoft Edge. Установка, сервер, аккаунт и интернет не нужны. Держите файлы сайта вместе: index.html, styles.css, app.js, video.js, preferences.js, icon.svg. Интерфейс на английском, как в исходной презентации.

Скачайте репозиторий через Code → Download ZIP и распакуйте его целиком или выполните git clone https://github.com/Avaai7/final.git. Папка tests предназначена для разработчика; для обычного запуска она не требуется.

## Image studio

- Пакетная загрузка с добавлением файлов, удалением, отменой и прогрессом.
- Auto с объяснением выбора и ручной выбор JPEG, PNG, WebP.
- Ограничения веса, длинной стороны, ширины и высоты с сохранением пропорций и без увеличения изображения.
- **Edit**: индивидуальные формат, качество, размеры, лимит веса и фон JPEG; поворот на 90/180/270 градусов; центральная обрезка в 1:1, 4:3, 16:9 и 9:16 с предпросмотром. Use global settings снимает индивидуальные настройки.
- **Format lab**: сравнение JPEG/PNG/WebP по весу, SSIM и времени кодирования. Любой пробный вариант можно скачать отдельно.
- Ползунок до/после, реальные пиксели 100% с прокруткой и подложка прозрачности. Для выравнивания оригинал получает те же поворот/обрезку и приводится к разрешению результата.
- ZIP с результатами и CSV-отчёт.
- Графика по умолчанию сохраняется в PNG. WebP с quality=1 не объявляется гарантированно lossless. Лимит веса при необходимости может потребовать lossy-экспорт — это поясняется.
- Возврат оригинала возможен только при выполнении всех ограничений размеров, отсутствии редактирования и меньшем весе.

Quality — параметр кодировщика, не процент сохранённого качества. Равные значения JPEG и WebP не гарантируют одинаковое визуальное качество.

SSIM рассчитан по яркости на приведённых к одинаковому размеру копиях до 800 px. Он не гарантирует сохранение цвета, альфа-канала, мелкого текста или исходной детализации. Значение 1 после уменьшения не означает равенства исходных пикселей. Проверяйте важные участки через Compare.

Format lab показывает пробные варианты до дополнительного уменьшения ради лимита веса. Итоговая карточка может иметь другие разрешение и качество. Время в таблице — только кодирование; время в карточке включает анализ и оценки.

## Video studio

- Загрузка одного браузерно-совместимого видео, включая MP4/H.264 и WebM. MOV/HEVC и другие сочетания зависят от декодера браузера.
- Размер, длительность, разрешение и контейнер оригинала.
- Предустановки Balanced, Small file и High quality.
- Исходное разрешение, 1080p, 720p, 480p, 360p; для вертикальных роликов границы разворачиваются. Увеличения разрешения нет.
- Видеобитрейт 0.15–20 Mbps; ограничение частоты кадров 15/24/30 fps.
- Обрезка по началу/концу и удаление аудиодорожки.
- Приблизительная оценка веса, прогресс, отмена и проигрыватели оригинала/результата.
- **WebM (VP9/VP8 + Opus)** и **MP4 (H.264 + AAC)** при поддержке записи браузером. Неподдерживаемые выходные форматы не показываются.
- Скачивание видео, JSON-отчёта и текущего кадра результата в PNG.
- Try a demo clip создаёт четырёхсекундный ролик с анимацией и тестовым тоном прямо на устройстве.

Видео декодируется браузером, кадры выводятся в Canvas, MediaRecorder записывает новый поток. Web Audio направляет исходный звук в экспорт, не в динамики. Камера и микрофон не используются.

Обработка идёт примерно со скоростью воспроизведения выбранного фрагмента. Держите вкладку активной; при её скрытии кодирование приостанавливается до возвращения. Для потокового WebM добавляются метаданные длительности, когда это возможно.

Битрейт и вес — целевые значения. Фактический результат зависит от содержимого и кодировщика и иногда может быть тяжелее оригинала. Интерфейс показывает измеренное изменение. При обрезке сокращение длительности тоже влияет на процент экономии. SSIM для видео не рассчитывается.

## Остальные возможности

Format guide: рекомендации для изображений, аудио и видео, калькулятор веса и таблица форматов.

Help & project: справка, ограничения, приватность, авторство, технические источники и проверка возможностей текущего браузера.

Светлая, тёмная и системная темы, увеличение текста. Глобальные параметры изображений, видео и оформление запоминаются на устройстве. Файлы, результаты и индивидуальные настройки файлов между перезагрузками не сохраняются.

## Ограничения

- Изображения: 60 MB и 40 мегапикселей. Видео: 150 MB, 5 минут и до 3840 × 2160 эквивалентных входных пикселей. Минимальный фрагмент — 0.25 секунды.
- GIF не конвертируется; анимированные WebP/PNG и распознаваемые последовательности HEIF/AVIF отклоняются.
- HEIC/AVIF и видеокодеки зависят от браузера. Поддержка всех контейнеров и кодеков, HDR и сохранения метаданных не реализована.
- Перекодирование через Canvas может удалить EXIF и изменить цветовые профили. Неизменённый оригинал сохраняет свои метаданные.
- Отмена изображения кооперативная: текущий вызов кодировщика завершается перед остановкой. Изображения и видео одновременно не перекодируются: изображения, добавленные во время обработки видео, ждут её окончания и затем запускаются автоматически.
- Память, скорость и доступные кодеки зависят от устройства. Реальные телефоны, Safari и Firefox требуют отдельной проверки.

## Проверки

Скрипты tests/smoke.cjs и tests/final.cjs требуют Node.js и Playwright. По умолчанию используется установленный Edge; для Chrome задайте переменную окружения MEDIAFIT_BROWSER=chrome. Из папки final запустите:

    node tests/smoke.cjs
    node tests/final.cjs

Проверяются изображения, индивидуальные настройки, обрезка и поворот, варианты экспорта, лимиты, CSV/ZIP, фактическое перекодирование видео, длительность WebM, ненулевой звук после экспорта, удаление аудиодорожки, MP4, JSON-отчёт, PNG-кадр, отмена, ошибки файлов, вкладки при ширине 390 px, увеличение текста и сохранение темы. Итоги находятся в tests/final-results-*.txt.

Мобильные проверки — эмуляция ширины в настольных браузерах, не реальный телефон. Это не полная проверка WCAG.

Сценарий демонстрации находится в DEMO.md. Презентация endterm не изменялась.
